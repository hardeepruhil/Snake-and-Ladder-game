# Snake and Ladder Game

A simple browser-based 2-player Snake and Ladder game built with vanilla HTML, CSS, and JavaScript.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Gameplay

- Two players alternate turns.
- Click **Roll Dice** to move.
- Landing on a ladder moves you up.
- Landing on a snake moves you down.
- You need an exact roll to reach 100.
